# MTMCT Framework

Локальное приложение для многокамерного трекинга людей: YOLO, ByteTrack,
OSNet и графовая ассоциация локальных треков в Global ID.

Видео и результаты обрабатываются на компьютере пользователя. Интерфейс позволяет
открывать результаты, смотреть камеры и мозаику, выбирать треки и просматривать
приблизительную карту перемещений.

## Запуск

В терминале из корня проекта:

```powershell
conda activate neuro_clean
python run.py app
```

Откройте http://127.0.0.1:8000/viewer . На Windows можно использовать
`run_web.cmd`. Остановка сервера — Ctrl+C.

Для первоначальной установки и сборки интерфейса см.
[инструкцию запуска](docs/START_HERE.md) и [подробности приложения](docs/WEB_INTERFACE.md).
PyTorch с подходящей CUDA и ReID-зависимости устанавливаются отдельно;
веса моделей и видео нужно разместить локально.

## Обработка видео хакатона

Пять файлов `camera_new_1.mkv` … `camera_new_5.mkv` разместите
в `data/Hackaton Data/`.

```powershell
python run.py office --seconds 120 --run-name office_my_run
```

Для трёх минут задайте `--seconds 180`. Каждый запуск требует нового имени.
Результаты: `runs/<имя>/mosaic.mp4`, CSV треков, JSON связей и диагностика.
Готовую папку можно открыть через «Новый набор» → «Открыть результат из проекта».

## Структура

| Каталог | Назначение |
|---|---|
| mtmct/ | Детекция, локальный трекинг, ReID, глобальная ассоциация и экспорт |
| backend/ | Локальный API и задания обработки |
| frontend/ | Веб-интерфейс |
| configs/ | Топология камер и параметры проекций |
| scripts/ | Диагностика и сравнение сохранённых результатов |
| experiments/ | Экспериментальные и ручные процедуры |
| docs/ | Инструкции и описание проекта |
| data/ | Локальные исходные видео и датасеты |
| weights/ | Локальные веса моделей |
| runs/ | Все результаты расчётов |
| run/ | Описание выбранных готовых прогонов |

[Карта проекта](docs/PROJECT_LAYOUT.md) объясняет расположение файлов.
В каждой основной папке есть README. Датасеты, веса, исходные видео,
локальные тесты и автоматические проверки GitHub в публикацию не входят.
Два выбранных готовых результата с мозаиками опубликованы в [run/](run/README.md).

## Текущее состояние

Офисный конвейер поддерживает разные FPS и ручные временные смещения,
фильтрацию размера людей и экранов, независимые кадры галереи, сопоставление
перекрывающихся камер по временным интервалам и предварительные гипотезы.

Удачный локальный ориентир: `runs/office_v2_120s_plan_fix_v1/`.
В нём найдено 10 ID при визуальном эталоне 9: начальный человек ещё разделён
между двумя ID. Трёхминутный прогон `office_v2_180s_temporal_overlap_v1`
завершён с 28 ID и требует разбора коротких треков в последней части.

Эвристические пороги пока не откалиброваны по разметке. Карта перемещений
приблизительная и не является точной метрической калибровкой.
Ручные правила из `experiments/` не применяются в автоматическом офисном прогоне.
