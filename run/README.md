# Выбранные результаты

Это локальная витрина готовых прогонов. Каталоги являются Windows junction:
они открывают исходные результаты из `runs/` без копирования больших видео.

* `office_120s/` → `runs/office_v2_120s_plan_fix_v1/`: удачный двухминутный прогон, подтверждённый вами.
* `office_previous/` → `runs/office_v2_120s_gallery_time_v2/`: предыдущий двухминутный результат для сравнения исправлений.

В каждом смотрите `mosaic.mp4` и `global_tracks_summary.json`.
У удачного двухминутного прогона остаётся известное разделение начального человека
на ID1/ID2: найдено 10 ID при вашем визуальном эталоне 9. Поэтому эта подборка
служит для сравнения, а не утверждает наличие объективно лучшей версии.

Новые расчёты сохраняются в `runs/`. Изменения файлов через эти ссылки также
изменят оригиналы. Для работы приложения импортируйте оригинальный путь `runs/...`.
