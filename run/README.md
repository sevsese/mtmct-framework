# Выбранные результаты

Готовые результаты скопированы в репозиторий для просмотра и сравнения.
Исходные видео камер и веса моделей сюда не включены.

* `office_120s/` → `runs/office_v2_120s_plan_fix_v1/`: удачный двухминутный прогон, подтверждённый вами.
* `office_180s/` → `runs/office_v2_180s_temporal_overlap_v1/`: последний трёхминутный результат, 28 Global ID.

В каждом смотрите `mosaic.mp4` и `global_tracks_summary.json`.
У удачного двухминутного прогона остаётся известное разделение начального человека
на ID1/ID2: найдено 10 ID при вашем визуальном эталоне 9. Поэтому эта подборка
служит для сравнения, а не утверждает наличие объективно лучшей версии.

В каждой папке опубликованы мозаика, карта, CSV/JSON треков, кэш признаков,
диагностика и реестр идентичностей. Пустые экспортные файлы пропущены.
Манифесты сохраняют пути исходной машины: для повторного расчёта на другом
компьютере нужны собственные исходные видео и настройка путей.

Новые расчёты сохраняются в `runs/`. Эти папки — отдельные копии завершённых
результатов. Локальный `office_previous/`, если присутствует, не публикуется.
