# Конфигурации

| Файл | Назначение |
|---|---|
| `camera_topology.json` | Топология и проверенные перекрытия камер офисного запуска |
| `hackaton_office_map_approx.json` | Приблизительные соответствия точек видео и плана |
| `hackaton_office_topology.json` | Отдельная конфигурация офисных переходов |
| `office_far_review.json`, `office_pass_review.json` | Данные для ручной проверки конкретных офисных прогонов |

Для первого запуска используйте настройки из проекта. Для произвольных видео
задавайте смещения в интерфейсе и привязывайте собственный план. Сохранённые
офисные проекции дают приблизительные координаты.
