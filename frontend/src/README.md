# Исходники веб-интерфейса

- `App.tsx` — навигация, загрузка, обзор, список треков и аналитика.
- `Viewer.tsx` — плееры камер, рамки и экспорт мозаики через API.
- `FloorPlan.tsx` — план помещения, привязки и траектории.
- `api.ts` — типы данных и запросы к локальному backend.
- `main.tsx` и `style.css` — вход приложения и стили.

Команды сборки находятся в [README интерфейса](../README.md).
