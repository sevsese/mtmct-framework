# Интерфейс

React-приложение локального просмотрщика. [src/](src/README.md) содержит
исходники. Из этой папки выполните `pnpm install --frozen-lockfile`, затем
`pnpm build`. Сборка появляется в `dist/` и выдаётся Python-сервером.

Для разработки запустите backend на 8000 и выполните `pnpm dev` в этой
папке. Ссылки и порядок запуска есть в [руководстве пользователя](../docs/START_HERE.md).
