# Локальные данные

Для офисного запуска создайте каталог `Hackaton Data` внутри `data/`.
Положите в него исходные MKV с такими именами.

| Имя файла | Camera ID | FPS | Смещение, с |
|---|---:|---:|---:|
| `camera_new_1.mkv` | 0 | 25 | 0 |
| `camera_new_2.mkv` | 1 | 25 | 1 |
| `camera_new_3.mkv` | 2 | 25 | 1 |
| `camera_new_4.mkv` | 3 | 20 | 4 |
| `camera_new_5.mkv` | 4 | 25 | 3 |

Скрипт `run_hackaton_experiment.py` ищет их именно в `data/Hackaton Data/`.
Сохраните исходные имена и формат. Для произвольного набора камер используйте
[загрузку в интерфейсе](../docs/START_HERE.md#3-обработать-свои-записи-в-браузере).

Приложение сохраняет отдельные копии файлов, загруженных через браузер, в
`data/web/<id>/input/`. Путь хранилища можно задать через `MTMCT_WEB_STORE`.
Исходные видео и это хранилище локальные и игнорируются Git. Если результат
использует оригиналы по абсолютным путям, их перемещение отключит видео
в этом результате.
