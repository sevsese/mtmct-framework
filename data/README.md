# Локальные данные

`hackaton/` — удобная ссылка на `Hackaton Data/` с пятью офисными видео.
Для актуального офисного запуска нужны только пять видео хакатона.
Данные не включаются в Git. Во время расчёта не переименовывайте исходные каталоги:
на их абсолютные пути ссылаются манифесты результатов.
