# Совместная работа

## Быстрый старт

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
```

PyTorch с подходящей CPU/CUDA-сборкой и `torchreid` устанавливаются отдельно по инструкции в README.

## Ветки и Pull Request

1. Обнови `main`: `git switch main && git pull`.
2. Создай короткую ветку: `feat/tracking-*`, `feat/reid-*`, `feat/geometry-*` или `feat/fusion-*`.
3. Не добавляй видео, веса, датасеты и содержимое `runs/`.
4. Перед push выполни `python -m pytest -q`.
5. Открывай небольшой PR с описанием метрики до/после и команды воспроизведения.

Изменения формата `observations.csv`, `local_tracklets.json` или `global_ids.json` требуют согласования всей команды, потому что эти файлы связывают рабочие блоки.

## Definition of Done

- тесты проходят;
- дорогой инференс не запускается повторно без необходимости;
- эксперимент сохраняет параметры и измеримые результаты;
- README обновлён, если изменилась команда запуска;
- в PR нет больших бинарных файлов.
