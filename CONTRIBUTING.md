# Совместная работа

Установка и запуск описаны в [docs/START_HERE.md](docs/START_HERE.md).

1. Обновите main и создайте отдельную ветку для своей задачи.
2. Сохраняйте параметры и результаты эксперимента в отдельном каталоге runs.
3. В описании изменений указывайте проблему, получившееся поведение и способ запуска.
4. Не публикуйте датасеты, веса, видео, локальные тесты и результаты инференса.
5. При изменении команд запуска обновляйте README.

Форматы observations.csv, local_tracklets.json и global_ids.json связывают
алгоритм с интерфейсом. Изменения этих форматов согласуйте с командой.
Автоматические проверки GitHub в этой поставке отключены.
