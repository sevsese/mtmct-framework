# Алгоритм MTMCT

Библиотека обработки: `tracking.py` — детекция и локальные треки; `reid.py` — признаки;
`scoring.py`, `identity_v2.py`, `overlap_matching.py` — глобальная ассоциация;
`identity_store.py` — реестр; `export.py`, `visualize.py` — результаты.
Общий запуск: из корня `python run.py office --seconds 120 --run-name office_new`.
