# Выбранные результаты

Готовые результаты скопированы в репозиторий для просмотра и сравнения.
Исходные видео камер и веса моделей сюда не включены.

* [office_120s/](office_120s/README.md) — двухминутный прогон, 10 Global ID.
* [office_180s/](office_180s/README.md) — последний пересчёт трёхминутного прогона, 26 Global ID.

В интерфейсе выберите «Новый набор» → «Открыть результат из проекта».
Таблицы появятся после импорта. Для готовой мозаики из этих примеров откройте
`mosaic.mp4` во внешнем плеере с поддержкой `mp4v`.
В двухминутном прогоне начальный человек получил два идентификатора, ID1 и ID2.
Алгоритм выдал 10 ID при визуальном подсчёте 9 человек.

В каждой папке опубликованы мозаика, карта, CSV/JSON треков, кэш признаков,
диагностика и реестр идентичностей. Пустые экспортные файлы пропущены.
Манифесты сохраняют пути исходной машины: для повторного расчёта на другом
компьютере нужны собственные исходные видео и настройка путей.

Новые расчёты из терминала сохраняются в отдельные подпапки `runs/`. Откройте
`global_tracks_2d.csv` для наблюдений с Global ID, `global_ids.json` для связей
Local → Global и `global_tracks_summary.json` для сводки. В `manifest.json`
сохранены входы и параметры. Новые результаты остаются локальными.
