# Командный план

## Сейчас

- [ ] Tracking: сравнить detector/tracker по detection recall и скорости.
- [ ] ReID: сравнить признаки на одинаковых сохранённых tracklets.
- [ ] Geometry: проверить проекцию на остальных train-сценах и построить 2D-карту пола.
- [ ] Fusion: автоматизировать Pairwise F1/IDF1 и журнал экспериментов.

## Затем

- [ ] Добавить топологию переходов для непересекающихся камер.
- [ ] Поддержать остальные классы Track 1 через `class_id` в артефактах.
- [ ] Подключить официальный 3D HOTA evaluator.
- [ ] Оценить online-режим без будущих кадров.

## Не сейчас

- Hydra и DVC — только когда обычных CLI-параметров и общего хранилища станет недостаточно.
- Детальная 3D-реконструкция помещения — только после работающего конкурсного 3D-экспорта.
- Отдельные интерфейсы для каждого компонента — после появления минимум двух реализаций.
