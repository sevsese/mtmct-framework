# План MTMCT Framework 2.0

Работа выполняется последовательно в локальной ветке `Sevsese-Branch`. Push и
merge выполняются только после отдельного разрешения.

| Этап | Результат | Статус |
|---|---|---|
| 00 | Аудит реального pipeline и измеренная отправная точка | выполнен локально |
| 01 | NVIDIA adapter, валидация и `inspect-scene` | выполнен локально |
| 02 | Версионированный Global 2D IDF1 и oracle-тесты | следующий |
| 03 | Manifest, независимые стадии и честный offline link-only | ожидает |
| 04 | Воспроизводимый full baseline и Oracle Tracklets | ожидает |
| 05 | Диагностика и агрегация ReID | ожидает |
| 06 | Tracklet refinement с provenance | ожидает |
| 07 | Constrained graph association и журнал решений | ожидает |
| 08 | Offline Global Memory | ожидает |
| 09 | Время, offsets и опциональная топология | ожидает |
| 10 | Обратимые association и identity correction | ожидает |
| 11 | WILDTRACK и проверка переносимости | ожидает |

Правила перехода: CPU unit/integration тесты должны быть зелёными; real-data
smoke и A/B выполняются только на доступных данных; отсутствие данных отмечается
как `NOT RUN`, а не заменяется синтетической метрикой. Новые алгоритмы остаются
выключенными по умолчанию без подтверждённого выигрыша на dev.
