# Руководство пользователя MTMCT

MTMCT отслеживает людей в видео с нескольких камер. Local ID обозначает трек
на одной камере. Global ID связывает локальные треки, которые алгоритм считает
одним человеком. Один человек может получить несколько Global ID, поэтому число
глобальных треков следует сверять с видео.

| Задача | Как запустить |
|---|---|
| Посмотреть готовый пример | Веб-интерфейс → «Открыть результат из проекта» |
| Обработать свои записи | Веб-интерфейс → «Исходные видео → обработка» |
| Обработать пять офисных камер | `python run.py office` или запуск `run_hackaton_experiment.py` в VS Code |
| Запустить из своего скрипта | Вызов офисного модуля или запросы к локальному API |

## 1. Установить и открыть приложение

Команды ниже рассчитаны на Windows PowerShell. Если проект уже скачан, откройте
терминал в его корне и пропустите первые две команды. Для установки нужны Git,
Python 3.11, Node.js и pnpm. Если у вас готовое Conda-окружение `neuro_clean`,
активируйте его и используйте `python` вместо `./.venv/Scripts/python.exe`.

```powershell
git clone https://github.com/sevsese/mtmct-framework.git
cd mtmct-framework
py -3.11 -m venv .venv
./.venv/Scripts/python.exe -m pip install opencv-python ijson -r backend/requirements.txt
cd frontend
pnpm install --frozen-lockfile
pnpm build
cd ..
./.venv/Scripts/python.exe run.py app
```

Откройте [локальное приложение](http://127.0.0.1:8000/). На Windows его также
можно запустить двойным щелчком по [run_web.cmd](../run_web.cmd) после сборки.
На Linux создайте окружение через `python3.11 -m venv .venv`, используйте
`.venv/bin/python` для установки и запустите `sh run_web.sh`. Оставьте терминал
с сервером открытым. Для остановки нажмите Ctrl+C.

Для просмотра готовых результатов хватит зависимостей сервера и собранного
интерфейса. Перед обработкой видео дополнительно установите PyTorch, зависимости
трекинга и веса по [инструкции моделей](../weights/README.md).

## 2. Открыть готовый результат

1. Нажмите «Новый набор» → «Открыть результат из проекта».
2. Выберите `runs/office_120s` или `runs/office_180s` и нажмите «Открыть результат».
3. В «Глобальных треках» появятся соответственно 10 или 26 Global ID.

Для результата из другой копии проекта положите папку с `global_tracks_2d.csv`
в `runs/`. Либо выберите режим «Готовые CSV / JSON» и загрузите
`global_tracks_2d.csv` или пару `observations.csv` + `global_ids.json`.
Можно добавить исходные видео с совпадающими Camera ID и смещениями.
Дополнительные файлы перечислены в [описании форматов](../backend/README.md).

У готовых офисных примеров манифесты ссылаются на пути исходной машины.
Поэтому при открытии из чистой копии видны таблицы, а готовую мозаику нужно открыть
из папки примера в плеере с поддержкой MPEG‑4 Part 2 (`mp4v`). Текущая версия
может использовать резервные 30 FPS для импортов без видео, даже если в
манифесте указан FPS камер. Для времени таких треков сверяйтесь с мозаикой или
считайте `frame_id / FPS + смещение` по манифесту и конфигурации.

## 3. Обработать свои записи в браузере

1. Откройте «Новый набор». Введите название и выберите «Исходные видео → обработка».
2. Выберите записи всех камер за один раз. Поддерживаются MP4, MOV, MKV и AVI
   до 4 ГиБ на файл. Для воспроизведения в браузере предпочтителен MP4 H.264.
3. Проверьте уникальные Camera ID, названия и смещения в секундах. Если событие
   произошло на первой камере на 5-й секунде, а на второй на 3-й, задайте
   второй камере смещение `+2` относительно первой.
4. Нажмите «Загрузить набор». После загрузки на странице «Обзор» появится
   панель «Обработка видео».
5. Для первой проверки укажите небольшой фрагмент, например 10 секунд.
   Нулевое ограничение означает всё видео. Если задать и секунды, и кадры,
   сработает меньший предел для каждой камеры. Выберите `cuda:0` при наличии
   совместимого NVIDIA GPU или `cpu`. Для штатного прогона оставьте «MTMCT 2.0».
6. Нажмите «Запустить обработку». Следите за этапом и журналом на странице
   «Обзор». После ошибки можно повторить запуск в том же наборе.

Для имён `camera_new_1.mkv` … `camera_new_5.mkv` интерфейс предлагает
Camera ID `0–4` и смещения `0, 1, 1, 4, 3` с. Для произвольной сцены
используйте собственную синхронизацию. Шаблонные имена офисных камер также
включают офисные настройки.

### Как читать и просматривать результат

| Раздел | Что делать |
|---|---|
| Обзор | Выбрать набор в верхней панели, посмотреть число камер и треков, ход обработки и предупреждения |
| Камеры | При подключённых видео смотреть отдельные камеры или нажать «Подготовить MP4» в синхронной мозаике. Для показа одного человека ввести Global ID |
| Глобальные треки | Искать по Global ID, фильтровать по камере и времени, открывать карточку и нажимать «Показать на видео» |
| Аналитика | Смотреть наблюдения по камерам и времени, длительности треков и скорость обработки |
| План помещения | Загрузить PNG/JPG, расставить камеры и привязать точки пола для приблизительных траекторий |
| Настройки | Проверять сохранённую конфигурацию, манифест, доступные файлы и предупреждения |

По умолчанию веб-загрузки хранятся в `data/web/<id>/input/`, вычисленные
результаты в `data/web/<id>/result/`, а журнал в `data/web/<id>/job.log`.
Если задана переменная `MTMCT_WEB_STORE`, используется указанный в ней каталог.

## 4. Запустить офисный анализ из файлов и терминала

Положите пять исходных MKV в [data/Hackaton Data](../data/README.md) с
именами `camera_new_1.mkv` … `camera_new_5.mkv`. Для этого сценария сохраните
исходный порядок камер: офисный пресет использует их FPS, смещения и топологию.
Для произвольных камер подходит загрузка в браузере или через API.

```powershell
./.venv/Scripts/python.exe run.py office --seconds 10 --run-name office_check_01
./.venv/Scripts/python.exe run.py office --seconds 120 --run-name office_2min_01
```

Выберите своё имя каталога для каждого нового запуска. CLI использует офисный
пресет с `cuda:0`. На компьютере без CUDA запустите CPU-вариант из следующего
раздела или выберите CPU в веб-интерфейсе. Для запуска из VS Code откройте
корень проекта, выберите интерпретатор окружения, откройте
[run_hackaton_experiment.py](../run_hackaton_experiment.py) и нажмите
«Run Python File». По умолчанию этот файл берёт первые 60 секунд каждой камеры.

Чтобы обработать видео до конца, вызовите офисный скрипт напрямую.
В этом режиме он сохраняет таблицы и сводку. Мозаику можно подготовить отдельно
через веб-интерфейс после подключения видео.

```powershell
./.venv/Scripts/python.exe run_hackaton_experiment.py --full --run-name office_full_01
```

По окончании откройте папку `runs/<имя>` или импортируйте её через меню.
Основные файлы — `mosaic.mp4` для ограниченного прогона,
`global_tracks_2d.csv` с кадрами и Global ID, `global_ids.json` со связями
Local → Global, `global_tracks_summary.json` со сводкой и `manifest.json`
с входными данными и параметрами. [Описание результатов](../runs/README.md).

## 5. Запустить анализ из Python

Сохраните следующий пример в корне проекта и выполните его тем же
интерпретатором. Это тот же офисный конвейер, который вызывает CLI.

```python
import run_hackaton_experiment as office

office.DEVICE = "cpu"  # Или "cuda:0" для NVIDIA GPU
office.RUN_NAME = "office_python_01"  # Выберите новое имя при повторе
office.main(duration_seconds=10, matcher="v2")
```

Запустите его из корня, например `./.venv/Scripts/python.exe analyze_office.py`.
Для других записей используйте [пример вызова локального API из Python](../backend/README.md#запуск-анализа-из-python).

## Если возникла ошибка

| Симптом | Что проверить |
|---|---|
| Интерфейс не собран | Выполните `pnpm install --frozen-lockfile` и `pnpm build` в `frontend/` |
| Страница не открывается | Проверьте, что сервер запущен, и прочитайте сообщение в терминале |
| Скрипт не находит камеры | Проверьте точное имя папки `data/Hackaton Data` и имена пяти MKV |
| Модель отсутствует | Проверьте `yolo26l.pt` в корне и OSNet IBN в `weights/` |
| CUDA out of memory | Выберите CPU или освободите память GPU. Ограничение длительности уменьшает время работы, но размер одного кадра сохраняется |
| Видео загружено, но не играет | Проверьте поддержку кодека браузером. При необходимости используйте копию в MP4 H.264 |
| Нет рамок или треков | Проверьте ID камер, смещения и обработанный интервал. Очень короткий прогон может отфильтровать все треки |
