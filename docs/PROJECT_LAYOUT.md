# Как устроен проект

| Папка | Содержимое |
|---|---|
| mtmct/ | Алгоритм: детекция, локальные треки, ReID, глобальная ассоциация, экспорт |
| backend/ | Локальный API и фоновые задания приложения |
| frontend/ | Интерфейс React |
| configs/ | Параметры камер, исключения, топология и проекции |
| scripts/ | Служебные инструменты, в том числе сравнение ассоциации |
| experiments/ | Экспериментальные и ручные процедуры |
| data/hackaton/ | Удобный локальный путь к пяти видео хакатона |
| weights/ | Локальные веса моделей |
| runs/ | Все результаты расчётов, кэши и журналы |
| run/ | Два выбранных готовых результата для быстрого просмотра |
| docs/ | Инструкции и история развития |

`run/` и `runs/` имеют разные роли. Все новые расчёты пишутся в `runs/`.
`run/office_120s/` и `run/office_180s/` содержат опубликованные копии выбранных
результатов с мозаиками. Исходные видео камер, веса и остальные результаты
из `runs/` не включаются в Git.

Начните с [инструкции запуска](START_HERE.md).
