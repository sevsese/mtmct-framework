# Как устроен проект

| Папка | Содержимое |
|---|---|
| mtmct/ | Алгоритм: детекция, локальные треки, ReID, глобальная ассоциация, экспорт |
| [backend/](../backend/README.md) | Локальный API и фоновые задания приложения |
| [frontend/](../frontend/README.md) | Интерфейс React и его сборка |
| [configs/](../configs/README.md) | Параметры камер, исключения, топология и проекции |
| [scripts/](../scripts/README.md) | Служебные команды, в том числе сравнение ассоциации |
| [experiments/](../experiments/README.md) | Экспериментальные и ручные процедуры |
| [data/](../data/README.md) | Исходные видео в `Hackaton Data/` и веб-хранилище |
| [weights/](../weights/README.md) | Установка моделей и локальные веса ReID |
| [runs/](../runs/README.md) | Результаты расчётов, кэши, журналы и два готовых примера |
| [docs/](README.md) | Руководство и технические справочники |
| [.github/](../.github/DESCRIPTION.md) | Шаблон описания изменений |

Все новые расчёты пишутся в `runs/`.
`runs/office_120s/` и `runs/office_180s/` содержат опубликованные копии выбранных
результатов с мозаиками. Исходные видео камер, веса и остальные результаты
из `runs/` не включаются в Git.

Начните с [инструкции запуска](START_HERE.md).
