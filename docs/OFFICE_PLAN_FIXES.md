# Исправления по диагностике двухминутного прогона

Использован сохранённый набор `office_v2_120s_gallery_time_v2`, без ручных
связей между ID и без переизвлечения признаков для сравнения ассоциации.

* Локальный разрыв до 1.8 с восстанавливается при ReID >= 0.70 и более строгом
  ограничении смещения бокса. Неоднозначные конкурирующие продолжения откладываются.
* Разрешённое перекрытие камер больше не даёт временной вес и не снижает ReID-порог.
  Проверка всех пар компонента блокирует обход слабой одновременной связи.
* Прототипы и галерея используют одну политику качества. Один качественный кадр
  допускается как свидетельство; он не считается несколькими ракурсами.
* Для последовательных наблюдений допускается поддержка повторяемого сходства
  галерей. Слабый промежуточный трек присоединяется только при поддержке двух
  камер уже сформированного компонента, допустимых маршрутах и отсутствии конфликтов.
* Короткий широкий одиночный трек, возникший рядом с двумя предшествующими людьми
  и перекрывавшийся с другим треком, получает `artifact_candidate`. Он сохраняется
  в диагностике, но не публикуется как новая личность и не обновляет память.
  Составной bbox проверяется до удаления вложенных боксов.

На том же кэше: фрагменты камеры 5 L1/L2 объединены; ошибочная связь камеры 4 L3
с камерой 5 L6 разделена, в том числе через обходные связи; камера 5 L18,
камера 4 L7 и камера 3 L4 образуют одну цепочку; камера 5 L10 помещена в карантин.
Нумерация камер здесь 1–5. Опубликовано 10 ID вместо прежних 12.

Компромисс: начальная пара камер 1/2 теперь разделяется из-за слабого ReID.
Её прежнее объединение зависело от снятого исключения для перекрывающихся камер.
Количество ID само по себе не является метрикой точности.

Новая проверка полного конвейера (окружение `neuro_clean`):

```powershell
conda activate neuro_clean
python -u run_hackaton_experiment.py --seconds 120 --run-name office_v2_120s_plan_fix_v1
```

Повторный запуск требует нового `--run-name`. Результат: `runs/<имя>/mosaic.mp4`,
`global_tracks_summary.json`, `association_edges.json`, `identity_state.json`.
Разрыв эпизода остаётся 60 с; лупа выключена на всех камерах.

Ограничения: пороги эвристические, геометрия ассоциации не откалибрована,
цвет волос и число голов отдельной моделью не определяются. Карантин групповых
боксов требует визуальной проверки; он может скрыть настоящее короткое наблюдение.
